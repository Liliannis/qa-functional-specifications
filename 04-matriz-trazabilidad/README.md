# Matriz de trazabilidad

La matriz relaciona historias de usuario, reglas de negocio, criterios de aceptacion y casos de prueba.

## Como leerla

1. Identificar la HU.
2. Revisar los criterios de aceptacion asociados.
3. Confirmar que cada criterio tenga al menos un caso de prueba.
4. Revisar estado de cobertura: cubierto, parcial o pendiente.
5. Usar los resultados de ejecucion para detectar riesgos sin validar.

## Objetivo QA

La matriz permite demostrar cobertura funcional y evitar que requisitos importantes queden sin pruebas.

## Nota

El archivo Excel puede mantenerse como fuente visual, pero este README explica el contexto para que la matriz no se vea como un documento aislado.
