# Playwright - Automatización en preparacion

Esta carpeta está reservada para futuras pruebas automatizadas con Playwright y TypeScript.

## Alcance inicial sugerido

- Login y acceso por roles.
- Validación de permisos administrativos.
- Flujo de validación de identidad.
- Validación de estados vacíos o errores controlados.

## Enfoque

La automatización debe partir de los casos funcionales existentes, no reemplazarlos. Primero se define el riesgo funcional, después se automatizan flujos repetibles y críticos.
