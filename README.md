# Portfolio QA - Especificaciones funcionales y trazabilidad

Este repositorio presenta un caso practico de QA funcional y analisis de requerimientos basado en escenarios profesionales anonimizados, generalizados y adaptados para portfolio.

> Nota de confidencialidad: este material no contiene informacion real ni confidencial de clientes. Los escenarios fueron modificados para proteger acuerdos de confidencialidad y se usan exclusivamente para demostrar metodologia de trabajo QA.

## Objetivo

Demostrar mi capacidad para transformar necesidades de negocio en artefactos QA trazables: FSD, historias de usuario, reglas de negocio, precondiciones, criterios de aceptacion, escenarios Gherkin, matriz de trazabilidad, evidencias de ejecucion y bugs encontrados simulados.

## Rol representado

QA Analyst / Functional Analyst, con foco en:

- analisis funcional;
- validacion de requisitos;
- diseno de casos de prueba;
- testing funcional y end-to-end;
- trazabilidad entre requisitos y pruebas;
- comunicacion de bugs encontrados;
- validacion de APIs y datos como linea de evolucion profesional.

## Como revisar el proyecto

1. Leer el contexto funcional y el FSD.
2. Revisar cada historia de usuario.
3. Consultar los casos de prueba en Gherkin.
4. Validar la cobertura en la matriz de trazabilidad.
5. Revisar evidencias de ejecucion manual simulada.
6. Revisar los bugs encontrados para entender analisis de impacto, severidad y prioridad.
