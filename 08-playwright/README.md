# Playwright - Automatizacion en preparacion

Esta carpeta esta reservada para futuras pruebas automatizadas con Playwright y TypeScript.

## Alcance inicial sugerido

- Login y acceso por roles.
- Validacion de permisos administrativos.
- Flujo de validacion de identidad.
- Validacion de estados vacios o errores controlados.

## Enfoque

La automatizacion debe partir de los casos funcionales existentes, no reemplazarlos. Primero se define el riesgo funcional, despues se automatizan flujos repetibles y criticos.
